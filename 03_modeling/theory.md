# Модуль 3 — Моделирование процессов и систем

## BPMN 2.0

BPMN (Business Process Model and Notation) — стандарт для визуального моделирования бизнес-процессов.

### Основные элементы

| Элемент | Описание |
|---|---|
| Начальное событие | Точка начала процесса |
| Конечное событие | Точка завершения процесса |
| Задача (Task) | Единица работы |
| Шлюз X (Exclusive) | Ветвление if/else |
| Шлюз + (Parallel) | Все ветки одновременно |
| Пул (Pool) | Участник процесса |
| Дорожка (Lane) | Роль внутри пула |

Инструменты: draw.io, Camunda Modeler, Bizagi

---

## UML-диаграммы

**Use Case Diagram** — взаимодействие акторов с системой
- Связи: include (обязательное), extend (опциональное)

**Sequence Diagram** — порядок взаимодействия компонентов во времени
- Фреймы: alt, loop, opt, par

**Activity Diagram** — поток управления (аналог блок-схемы)

**Class Diagram** — структура данных
- Связи: ассоциация, агрегация, композиция, наследование
