## Инструменты

### Моделирование
- [draw.io / diagrams.net](https://app.diagrams.net) — бесплатно, BPMN/UML/ERD
- [Camunda Modeler](https://camunda.com/download/modeler/) — BPMN 2.0
- [Miro](https://miro.com) — онлайн-доска для мозговых штурмов
- [Lucidchart](https://lucidchart.com) — профессиональные диаграммы

### Документирование
- [Confluence](https://www.atlassian.com/software/confluence) — корпоративная вики
- [Notion](https://notion.so) — гибкая документация
- [GitBook](https://gitbook.com) — документация в git

### API и тестирование
- [Postman](https://postman.com) — тестирование API
- [Swagger Editor](https://editor.swagger.io) — редактирование OpenAPI
- [Insomnia](https://insomnia.rest) — альтернатива Postman

### Управление задачами
- [Jira](https://atlassian.com/software/jira) — стандарт индустрии
- [YouTrack](https://jetbrains.com/youtrack/) — альтернатива Jira
- [Trello](https://trello.com) — простое Kanban-доска
- [Linear](https://linear.app) — современный трекер задач

### Прочее
- [Figma](https://figma.com) — прототипирование UI
- [dbdiagram.io](https://dbdiagram.io) — ER-диаграммы онлайн
- [PlantUML](https://plantuml.com) — UML через текст/код
