## 📋 Учебный план

### Модуль 1 — Основы системного анализа (1–2 недели)
- Роль и задачи системного аналитика
- Жизненный цикл разработки ПО (SDLC)
- Waterfall vs Agile vs Scrum
- Взаимодействие с командой: PM, разработчики, QA, бизнес

### Модуль 2 — Сбор и управление требованиями (2–3 недели)
- Виды требований: бизнес, функциональные, нефункциональные
- Техники сбора: интервью, workshop, анализ документов
- Пользовательские истории (User Stories) и критерии приёмки
- Документирование: BRD, SRS, Backlog

### Модуль 3 — Моделирование процессов и систем (2 недели)
- BPMN 2.0: нотация и инструменты (Camunda, draw.io)
- UML-диаграммы: Use Case, Sequence, Activity, Class
- ER-диаграммы и основы баз данных
- C4 Model: архитектурные диаграммы

### Модуль 4 — API и интеграции (1–2 недели)
- REST API: методы, статус-коды, JSON
- Чтение Swagger / OpenAPI документации
- Основы интеграционных паттернов
- Работа с Postman

### Модуль 5 — Практические кейсы (2 недели)
- Разбор реальных ситуаций из CRM, маркетплейсов, банкинга
- Написание ТЗ по готовому кейсу
- Peer review документов

## 📌 Ожидаемые результаты

После завершения курса студент умеет:

- [ ] Описывать бизнес-процессы в нотации BPMN
- [ ] Составлять User Stories с критериями приёмки (INVEST)
- [ ] Писать функциональные требования и ТЗ
- [ ] Читать и описывать REST API
- [ ] Строить UML-диаграммы (Use Case, Sequence)
- [ ] Работать с командой в Agile-среде
- [ ] Проводить интервью с заказчиком
