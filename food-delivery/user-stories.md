# User Stories — Приложение доставки еды «FoodRun»

> Пет-проект: описываю требования к мобильному приложению доставки еды.
> Роль: системный аналитик. Инструменты: Notion, draw.io.

---

## Эпик: Оформление заказа

### US-001 — Выбор ресторана

**Как** покупатель,
**я хочу** видеть список ресторанов поблизости с рейтингом и временем доставки,
**чтобы** быстро выбрать подходящее место.

**Критерии приёмки:**

```
Given: пользователь на главном экране
When: нажимает «Рестораны»
Then: отображается список, отсортированный по расстоянию

Given: список ресторанов открыт
When: выбирает фильтр «Пицца»
Then: показаны только рестораны с пиццей

Given: геолокация за городом
When: открывает список ресторанов
Then: сообщение «Рестораны не найдены»
```

**Приоритет:** Must | **Оценка:** 5 SP

---

### US-002 — Добавление блюда в корзину

**Как** покупатель,
**я хочу** добавлять блюда в корзину прямо из меню,
**чтобы** собрать заказ без лишних переходов.

**Критерии приёмки:**

```
Given: открыто меню ресторана
When: нажимает «+» рядом с блюдом
Then: блюдо добавлено, счётчик корзины +1, сумма пересчитывается

Given: блюдо уже в корзине
When: нажимает «+» снова
Then: количество увеличивается, итоговая сумма пересчитывается

Given: ресторан временно закрыт
When: пытается добавить блюдо
Then: кнопка «+» неактивна, тултип: «Ресторан закрыт»
```

**Приоритет:** Must | **Оценка:** 3 SP

---

### US-003 — Оформление заказа

**Как** покупатель,
**я хочу** указать адрес доставки и оплатить заказ,
**чтобы** оформить всё за минимальное количество шагов.

**Критерии приёмки:**

```
Given: корзина заполнена
When: нажимает «Оформить заказ»
Then: заказ создаётся, приходит push-уведомление с номером

Given: поле адреса пустое
When: нажимает «Оформить заказ»
Then: поле подсвечивается красным, ошибка «Введите адрес доставки»

Given: выбран способ оплаты «Карта»
When: подтверждает заказ
Then: открывается экран 3DS-оплаты
```

**Приоритет:** Must | **Оценка:** 8 SP

---

### US-004 — Отслеживание заказа

**Как** покупатель,
**я хочу** видеть статус заказа и позицию курьера на карте,
**чтобы** понимать, когда ждать доставку.

**Критерии приёмки:**

```
Given: заказ оформлен и принят рестораном
When: ресторан обновил статус
Then: статус меняется на «Готовится», push-уведомление пользователю

Given: заказ передан курьеру
When: пользователь открывает приложение
Then: на карте видна метка курьера, обновляется каждые 30 сек

Given: курьер отметил доставку
When: — (автоматически)
Then: статус «Доставлен», появляется форма оценки
```

**Приоритет:** Should | **Оценка:** 13 SP

---

## Нефункциональные требования

- Список ресторанов загружается менее чем за **2 секунды**
- Статус заказа обновляется не реже **раз в 30 секунд**
- Данные карты передаются через **PCI DSS**-совместимый шлюз
- Приложение работает при скорости соединения от **2G**
