# Задания — Модуль 1: Основы системного анализа

## Задание 1.1 — Анализ ролей в команде

**Цель:** Понять, как SA взаимодействует с другими участниками проекта.

**Задание:**
1. Выберите любой известный вам продукт (мобильное приложение, сайт, сервис)
2. Опишите команду, которая могла работать над ним (минимум 5 ролей)
3. Для каждой роли укажите: задачи, ответственность, как они взаимодействуют с SA
4. Оформите в виде таблицы

**Ожидаемый результат:** Таблица в формате Markdown (минимум 5 строк)

---

## Задание 1.2 — Сравнение методологий

**Цель:** Разобраться в различиях между Waterfall и Agile.

**Задание:**
1. Придумайте 2 проекта: один подходит для Waterfall, другой — для Agile
2. Для каждого проекта обоснуйте выбор методологии (минимум 3 аргумента)
3. Опишите роль SA в каждом проекте

**Ожидаемый результат:** Документ с описанием проектов и обоснованием (200–300 слов)

---

## Задание 1.3 — Карта стейкхолдеров

**Цель:** Научиться определять заинтересованных лиц проекта.

**Задание:**
Дано: Компания хочет разработать внутреннюю систему учёта рабочего времени сотрудников.

1. Определите всех стейкхолдеров проекта
2. Классифицируйте их по матрице "Влияние / Интерес"
3. Для каждого стейкхолдера укажите его ожидания от системы

**Матрица стейкхолдеров:**
```
Высокое влияние + Высокий интерес → Тесное сотрудничество
Высокое влияние + Низкий интерес  → Держать в курсе
Низкое влияние  + Высокий интерес → Информировать
Низкое влияние  + Низкий интерес  → Наблюдать
```

**Ожидаемый результат:** Заполненная матрица + таблица ожиданий
