# Кейс 1 — CRM-система для отдела продаж

## Описание кейса

Компания "АльфаТрейд" — дистрибьютор электроники, 150 сотрудников. Отдел продаж (20 менеджеров) ведёт клиентов в Excel. Руководство хочет внедрить CRM-систему.

**Проблемы:**
- Менеджеры не видят историю взаимодействий коллег с клиентами
- Нет автоматических напоминаний о звонках
- Сложно строить отчёты по продажам
- Данные теряются при увольнении сотрудников

## Задание для студента

### Часть 1: Сбор требований

1. Составьте список вопросов для интервью с директором по продажам
2. Составьте список вопросов для интервью с менеджером по продажам
3. Определите: какие данные нужно хранить о клиенте?

### Часть 2: Документирование требований

Напишите минимум 5 User Stories в формате:
> Как [роль], я хочу [действие], чтобы [цель]

Для каждой User Story укажите критерии приёмки (минимум 2 сценария).

### Часть 3: Моделирование

1. Нарисуйте BPMN-диаграмму процесса "Обработка входящего лида" (As-Is в Excel)
2. Нарисуйте BPMN-диаграмму того же процесса в CRM (To-Be)
3. Постройте Use Case диаграмму для ролей: Менеджер, Руководитель, Администратор

### Часть 4: API

Опишите API-эндпоинты для следующих операций:
- Создать нового клиента
- Получить список клиентов (с фильтрацией по менеджеру)
- Обновить статус сделки
- Получить историю взаимодействий по клиенту
